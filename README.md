# Игры для iPad mini (iOS 9.3.6)

**Целевое устройство: iPad mini 1-го поколения, iOS 9.3.6.** Весь код должен работать в том Safari без современных API.

Набор развивающих HTML-игр для ребёнка ~6 лет.

Нужен **Node.js**. Зависимостей нет — только встроенные модули.

## Команды

```bash
npm run appcache   # app.appcache + escape offline.appcache + icons/manifest
npm run serve      # локальный сервер (MIME text/cache-manifest)
npm start          # appcache + serve
npm run deploy     # сборка + пуш в ветку gh-pages (GitHub Pages)
```

## GitHub Pages

1. Создайте пустой репозиторий на GitHub (без README, если ещё нет remote).
2. Один раз:

```bash
git remote add origin git@github.com:USER/REPO.git
git push -u origin main
npm run deploy
```

3. В репозитории: **Settings → Pages → Branch: `gh-pages` / `/ (root)` → Save**.

4. Сайт: `https://USER.github.io/REPO/`

На iPad один раз откройте сайт **онлайн** → «На экран Домой» → дальше можно офлайн.

## Залип старый кэш с экрана «Домой»

У Safari и ярлыка «Домой» на iOS **разные** AppCache. Удалить ярлык недостаточно; кнопка «Обновить» в Safari на ярлык не действует.

1. Нужен интернет.
2. **Настройки → Safari → Очистить историю и данные**.
3. Откройте сайт снова в Safari → «На экран Домой».

Страница-подсказка (без AppCache): `https://USER.github.io/REPO/fresh.html`

После деплоя новой версии откройте ярлык **с интернетом** — скрипт сам делает `update` + `swapCache` + reload.

## Локально с Mac по Wi‑Fi

```bash
npm start
```

На iPad: `http://192.168.x.x:8080` (IP печатает сервер).

## Управление

- **🏠 Домой** и **🔄 Обновить** в играх и на главной.
- Уровни, «Следующий уровень» в попапе.
- Долгое нажатие (~2 сек) на «Игры» — сброс прогресса.

## Игры

**Чтение:** Сложи слово, Найди пару, Вставь букву, Прочитай и сделай  
**Счёт:** Что больше?, Простые примеры  
**Мир:** Что лишнее?, Времена года, Кто что делает  
**Память:** Мемори, Повтори, Что пропало?, Запомни и найди  
**Логика:** Найди отличия, Продолжи ряд, Лабиринт  
**Моторика:** Собери пазл
